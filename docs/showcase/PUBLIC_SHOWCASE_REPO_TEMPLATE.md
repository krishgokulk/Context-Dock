# Public Showcase Repository Template

Create a separate public repository (not this one) with:

- Product overview
- High-level architecture diagram (no sensitive internals)
- Screenshots and/or demo video
- Limited non-sensitive sample code

## Suggested structure
- `README.md` (overview + problem/solution)
- `docs/architecture.md` (high-level only)
- `media/` (screenshots/video links)
- `samples/` (sanitized snippets)

## Redaction rules
- Remove credentials, internal URLs, and private identifiers.
- Exclude proprietary algorithms and private integration details.
- Keep only enough technical depth to prove capability.
