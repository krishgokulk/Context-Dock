# Monthly Evidence Update Routine

Run this once per month:

- Archive new achievements/milestones with dates.
- Snapshot key metrics (usage, growth, reliability, impact).
- Add new testimonials, references, media, talks, and publications.
- Update the evidence timeline index.
- Refresh narrative claim-to-evidence mapping.
- Watermark sensitive decks/docs shared externally.
- Verify private storage access control and backups.
