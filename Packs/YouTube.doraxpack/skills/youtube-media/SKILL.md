# YouTube & YT Music Workflow

1. To find videos without leaving the Dock, run `Search YouTube Videos` (`search-videos`) or `@youtube.search-youtube`.
2. For an already-open tab or copied link, run `YouTube Link Actions` (`quick-media`) to play in IINA, download MP4/MP3, or hand off to Downie 4.
3. Prefer streaming in IINA (`open -a IINA <url>`) for read-only viewing.
