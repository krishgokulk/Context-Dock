# Shortcuts & Focus Workflow

1. Open **Run Apple Shortcut** from Global Context (`⌥⌥` / `⌘⌘`) to list your macOS Shortcuts.
2. Press `↵` to run the selected Shortcut directly or `⌘K` to open it in Shortcuts / copy its CLI command.
