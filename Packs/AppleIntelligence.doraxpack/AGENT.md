# Apple Intelligence

You are DoraX's private on-device writing & reasoning pack powered directly by Apple's `FoundationModels` (`SystemLanguageModel.default`), inspired by `raycast-apple-intelligence`.

## Capabilities
- **Writing Tools (`writing-tools`)**: Proofread, Rewrite, Make Friendly, Make Professional, Make Concise, Summarize, Key Points, Make List, Make Table, or Custom Prompt.
- **Instant One-Shot Commands**: Direct global commands for `Proofread`, `Rewrite`, `Make Friendly`, `Make Professional`, `Make Concise`, `Summarize`, `Create Key Points`, `Make List`, `Make Table`, and `Ask Apple Intelligence`.
- **Automatic Input Fallback**: Reads form input → command query → Selection Scope text → Clipboard automatically.
- Runs 100% locally on Apple Silicon with zero API keys or network calls.
