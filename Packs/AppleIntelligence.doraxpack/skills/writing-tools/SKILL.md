# Apple Intelligence Writing Tools

1. Select text or copy text to the clipboard (`⌘C`).
2. Summon Global Context (`⌥⌥` / `⌘⌘`) and search any tool (`Proofread`, `Rewrite`, `Make Concise`, `Make Friendly`, `Make Professional`, `Summarize`, `Create Key Points`, `Make List`, `Make Table`).
3. Press `↵` to copy the improved output immediately, or open **Apple Intelligence Writing Tools** for multi-step transformations.
