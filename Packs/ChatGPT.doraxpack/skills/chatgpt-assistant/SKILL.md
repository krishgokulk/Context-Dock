# ChatGPT Workflow

1. Run **Ask ChatGPT** to send a query to `chatgpt.com`, open a Temporary Chat, or activate ChatGPT Desktop with the prompt copied.
2. Open **ChatGPT Quick Actions** for one-tap Desktop/Web navigation.
