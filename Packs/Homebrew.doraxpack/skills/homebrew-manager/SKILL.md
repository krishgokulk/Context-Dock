# Homebrew Workflow

1. Open **Installed Brew Packages** or **Outdated Brew Packages** from Global Context (`⌥⌥` / `⌘⌘`).
2. Filter between `Formula` and `Cask` from the top-right dropdown.
3. Use `⌘K` actions to copy `brew info` / `brew upgrade`, or trigger confirmed upgrades.
