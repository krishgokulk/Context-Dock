# GitHub Workflow

1. Open `My Pull Requests`, `My Assigned Issues`, or `My Repositories` from Global Context or when browsing `github.com`.
2. Press `↵` to open an item in your browser or use `⌘K` to copy URLs, PR numbers, or SSH/HTTPS clone URLs.
3. Ask AI `@github.search-repos <topic>` to search GitHub headlessly.
