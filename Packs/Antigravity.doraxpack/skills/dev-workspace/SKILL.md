# Dev Workspace Management

When helping with development workspace tasks:

1. **Identify** the current workspace and project directory.
2. **Check** git status, branch, and any uncommitted changes.
3. **Suggest** actions based on the state: commit, stash, branch, or push.
4. **Execute** approved commands one at a time with output verification.
5. **Report** the result of each command before proceeding to the next.

For multi-step workflows (build, test, deploy), present the full plan first and get approval.
