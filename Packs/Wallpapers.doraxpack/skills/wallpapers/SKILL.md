# Wallpapers

- Use `next_wallpaper` when the user wants the next or random desktop background.
- Prefer **Browse Wallpapers** for picking a folder (`pick_folder`) or adding individual pictures (`pick_files`) into `~/Library/Application Support/Context-Dock/wallpapers/collection`.
- Never delete files from the user's external wallpaper folder; only files copied into `collection` can be removed.
