# Wallpapers Pack

Manage desktop wallpapers and backgrounds across all Spaces and displays.

- **Next Wallpaper**: Advances cleanly through your configured Wallpaper Folder (or auto-detected active desktop folder) plus any individually added pictures.
- **Browse Wallpapers**: Visual grid preview where you can set any picture (`⏎`), choose a folder (`⌘O`), add individual pictures (`⌘I`), shuffle, or remove added pictures.
- **Random Wallpaper**: Picks a random wallpaper other than the current one.
