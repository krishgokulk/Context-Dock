# Email Triage

When asked to triage or organize the inbox:

1. **Fetch** unread messages via `mail.unread`.
2. **Categorize** by urgency: Action Required, FYI, Automated/Newsletter.
3. **Summarize** each message in one line: sender, subject, and action needed.
4. **Recommend** which to reply to first, based on recency and sender importance.
5. **Wait** for the user to pick a message before drafting a reply.

Never mark messages as read or move them without explicit instruction.
