# System & Hardware Workflow

1. Run **Appearance Mode**, **Wi-Fi Inspector**, **Bluetooth Devices**, **Volume Controls**, or **Keep Awake** directly from Global Context (`⌥⌥` / `⌘⌘`).
2. Press `↵` to apply a card or copy device/IP info; use `⌘K` for secondary system preferences links.
