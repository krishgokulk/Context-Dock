# Media Inspection

When asked about a video or audio file:

1. **Identify** the file currently open in IINA (or the file path the user provided).
2. **Read** media metadata: codec, resolution, frame rate, bitrate, audio tracks, subtitle tracks.
3. **Summarize** in a compact table format.
4. **Note** any quality issues: low bitrate, non-standard codec, missing audio.

For playlist inspection, list items with duration and file size when available.
