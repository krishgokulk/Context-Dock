# Non-Destructive File Organization

When asked to clean up or organize a folder:

1. **Scan** the folder contents (names, types, sizes, modification dates).
2. **Propose** a dry-run table: each file → proposed destination folder.
3. **Wait** for the user to approve, modify, or reject the plan.
4. **Execute** only the approved moves, one at a time, with verification.
5. **Report** what was moved and what was left in place.

Never delete files during organization. If duplicates are found, list them for the user to decide.
